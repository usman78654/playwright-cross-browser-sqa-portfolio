# Exploratory Test Charters

Use 30-minute, time-boxed sessions. Record environment, data, observations, questions, defects, and follow-up ideas.

| Charter | Mission | High-value variations |
|---|---|---|
| 1. Authentication and session | Explore ways authentication state can become invalid or inconsistent | Direct URLs, expired/corrupt cookie, logout, back button, two tabs |
| 2. Catalog and cart | Challenge product identity, sorting, and cart totals | Rapid clicks, refresh, reset, duplicate tabs, special users |
| 3. Checkout interruption | Explore loss or duplication during purchase | Back/forward, refresh each step, blank/boundary data, offline transition |
| 4. Responsive and accessible use | Complete purchase without relying on a desktop mouse | Keyboard, 200–400% zoom, orientation, forced colors, touch targets |
| 5. Weak network | Identify misleading or blocked states during degraded connectivity | Slow 3G, failed images, offline/recovery, cached pages |
