# Manual Accessibility Checklist

Automated scanning cannot validate the full user experience. Complete this checklist before claiming accessibility conformance.

- Complete login, cart, and checkout using keyboard only.
- Confirm a visible focus indicator and logical focus order.
- Confirm errors receive focus or are announced by a screen reader.
- Test NVDA with Firefox or Chrome on Windows.
- Verify landmark, heading, field-label, button, and link announcements.
- Test 200% and 400% zoom without loss of content or function.
- Test Windows High Contrast / forced-colors mode.
- Confirm meaning does not rely on color alone.
- Check touch target size and spacing on a physical mobile device.
- Record tester, assistive technology version, browser, findings, and evidence.
